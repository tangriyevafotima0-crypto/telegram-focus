# Telegram Focus — AI Mentorship & Onboarding Engine

An evolving, production-grade asynchronous Telegram bot platform integrating Google Gemini AI and Telethon for intelligent user onboarding, automated briefing, and context-aware mentorship workflows.

## System Architecture
- **Inference & Intelligence:** Google Gemini Pro API (context-aware prompt routing and dynamic onboarding).
- **Client Layer:** Telethon (MTProto API asynchronous event listener and session management).
- **Supervision & Reliability:** Environment isolation, secret management, and session health checks.

## Engineering Evolution
- **v1.0 Baseline:** Core Telegram event handling, onboarding state machine, and basic Telethon integration.
- **v5-FINAL:** Deep integration with Google Gemini Pro via Google AI Studio API, multi-turn conversational context, and automated briefing logic.

- Source modules containing bot handlers, MTProto client sessions, and AI integration loops.
